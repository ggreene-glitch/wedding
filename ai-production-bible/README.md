# Acqualina AI Production Bible

This folder teaches AI image and video models how to imagine an outdoor wedding at Acqualina Resort & Residences with consistency.

It is not an engineering digital twin. It is a cinematic location bible: a practical reference for describing the venue, its visual language, the wedding atmosphere, and reusable prompt blocks.

## Goal

Enable an AI video generator to create believable wedding scenes at Acqualina by preserving:

- the Mediterranean oceanfront estate feeling
- cream stucco architecture and terracotta accents
- mature palm framing
- the Great Lawn as the primary outdoor wedding space
- broad pale beach and Atlantic horizon beyond
- Acqualina red as a property accent, not the wedding palette
- warm editorial wedding cinematography

## Folder Structure

```text
00_identity/      Core mental model of the venue
01_location/      Layout, style, and place-specific description
07_prompts/       Master prompts, negative prompts, and consistency rules
```

## How to Use

Start with `00_identity/property_overview.md`, then use `07_prompts/master_prompt.md` as the base for image or video generation.

For each future video prompt, combine:

1. location language
2. lighting language
3. camera movement
4. wedding moment
5. negative constraints
